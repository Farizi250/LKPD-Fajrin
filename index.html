D APERSEPSI

Bayangkan kamu sedang membuat aplikasi data siswa. Program perlu mengetahui: Nama siswa ("Budi"), Kelas ("XI RPL 1"), Umur (16), Nilai (85), Jurusan.

Menurutmu, bagaimana cara menyimpan informasi tersebut di dalam program? Tuliskan dugaanmu:

Menggunakan variabel sebagai wadah penampung data di dalam memori komputer, sehingga masing-masing data diberi label/nama agar dapat dipanggil dan diproses kembali oleh program.

E AKTIVITAS 1 — MENGAMATI

Perhatikan kode berikut:

let nama = "Budi";
let umur = 16;
let nilai = 85;
console.log(nama);
console.log(umur);
console.log(nilai);
1. Apa yang ditampilkan pada Console?

Console menampilkan tiga baris hasil: Budi, 16, dan 85.

2. Menurutmu, apa fungsi nama, umur, dan nilai?

nama, umur, dan nilai adalah variable, yaitu wadah yang berfungsi menyimpan data ("Budi", 16, dan 85) agar bisa dipanggil lagi.

3. Apa yang terjadi jika kode console.log(nama); dijalankan?

Console menampilkan isi dari variable nama, yaitu Budi.

4. Menurut dugaanmu, apa yang dimaksud dengan variable?

Variabel adalah tempat atau wadah di dalam memori program yang digunakan untuk menyimpan suatu data agar dapat dipanggil dan digunakan kembali.

H AKTIVITAS 4 — EKSPERIMEN

1. Apakah hasil pada Console berubah saat data diubah?

Ya, hasil pada Console ikut berubah sesuai dengan data yang diubah.

2. Bagian kode mana yang kamu ubah?

Bagian nilai yang berada di sebelah kanan tanda =, misalnya "Budi" diganti dengan nama lain.

3. Mengapa program dapat menampilkan data yang baru?

Karena console.log() membaca nilai terbaru yang tersimpan di dalam variable, sehingga yang tampil selalu isi variable saat itu.

VariableNilaiJenis Data

Kesimpulan: Data yang ditulis menggunakan tanda kutip seperti "Andi" merupakan data String (Teks), sedangkan angka tanpa kutip seperti 17 merupakan data Number (Angka).

J AKTIVITAS 6 — MENGENAL let DAN const

Uji coba let (dapat diubah): Menampilkan angka 17.

Uji coba const (diubah): Menghasilkan Error (TypeError).

KeywordNilai dapat diubah?Kegunaan sederhana
letYaUntuk data yang nilainya masih mungkin berubah (seperti skor, umur, nilai).
constTidakUntuk data yang nilainya tetap/konstan (seperti nama sekolah, tanggal lahir).

PERHATIKAN JUGA

JavaScript membedakan huruf besar dan kecil.

let nama = "Andi";
console.log(nama);

berbeda dengan:

console.log(Nama);

Q AKTIVITAS 13 — THINK PAIR SHARE

Mengapa programmer membutuhkan variable?

Programmer membutuhkan variabel untuk menyimpan, mengelola, dan memanipulasi data secara dinamis di dalam memori komputer, sehingga program tidak perlu menulis ulang data secara manual setiap kali digunakan.

S REFLEKSI 3-2-1

3 Hal yang Saya Pelajari:
  1. Variable adalah wadah untuk menyimpan data di dalam memori program.
  2. Cara membuat variable dengan let (nilai bisa diubah) dan const (nilai tetap).
  3. Cara menampilkan isi variable ke Console menggunakan console.log().
2 Hal yang Masih Membingungkan:
  1. Perbedaan penggunaan let dan const pada kasus tertentu.
  2. Aturan penamaan variable agar tidak terjadi error.
1 Hal yang Ingin Saya Coba:
  1. Membuat program data diri atau data produk yang lebih lengkap dengan lebih banyak variable.

T KESIMPULAN

  1. Variable adalah wadah/tempat menyimpan data sementara di dalam memori program.
  2. let digunakan untuk membuat variabel yang nilainya masih dapat diubah/diperbarui.
  3. const digunakan untuk membuat variabel yang nilainya bersifat tetap dan tidak boleh diubah.
  4. Untuk menampilkan isi variable ke Console kita dapat menggunakan console.log()

D. Apersepsi

Bayangkan kamu sedang membuat aplikasi data siswa. Program perlu mengetahui nama siswa, kelas, umur, nilai, dan jurusan.

Dugaan cara menyimpan informasi:
Informasi dapat disimpan menggunakan variabel JavaScript. Kata kunci let digunakan untuk nilai yang dapat berubah, sedangkan const digunakan untuk nilai yang tetap. Teks ditulis sebagai string dan angka ditulis sebagai number.

E. Aktivitas 1 – Mengamati

let nama = "Budi";
let umur = 16;
let nilai = 85;
console.log(nama);
console.log(umur);
console.log(nilai);
Jawaban pertanyaan:
  1. Console menampilkan Budi, 16, dan 85.
  2. Variabel nama, umur, dan nilai berfungsi menyimpan data nama, umur, dan nilai.
  3. console.log(nama) menampilkan isi variabel nama, yaitu Budi, ke Console.
  4. Variabel adalah tempat untuk menyimpan data agar dapat digunakan kembali di dalam program.

F. Aktivitas 2 – Mengenal Variabel

Struktur dasar penulisan variabel:

let nama = "Andi";
let

Kata kunci untuk membuat variabel.

nama

Identifier atau nama variabel.

=

Operator untuk memberikan nilai.

"Andi"

Nilai teks yang disimpan (string).

G. Aktivitas 3 – Praktik Membuat Variabel

Contoh hasil pengamatan Console browser setelah program dijalankan:

Nama : Fajrin
Kelas : X PPLG 2
Umur : 16
Kesimpulan: Program menampilkan nilai yang telah disimpan di dalam variabel melalui perintah console.log().

H. Aktivitas 4 – Eksperimen

  1. Apakah hasil pada Console berubah? Ya, hasil berubah sesuai dengan data baru yang dimasukkan ke dalam variabel.
  2. Bagian kode mana yang diubah? Nilai yang berada di sebelah kanan tanda sama dengan (=).
  3. Mengapa program dapat menampilkan data baru? Karena program membaca nilai terbaru yang tersimpan pada variabel ketika kode dijalankan.

J. Aktivitas 6 – Mengenal let dan const

KeywordNilai dapat diubah?Kegunaan
letYaUntuk variabel yang nilainya dapat diperbarui.
constTidak dapat di-assign ulangUntuk nilai yang tidak perlu diganti.
Perbedaan utamanya adalah let mengizinkan pemberian nilai baru, sedangkan const tidak mengizinkan penugasan ulang setelah deklarasi.

K. Aktivitas 7 – Aturan Penamaan Variabel

  • Boleh menggunakan huruf, angka, garis bawah (_), dan tanda dolar ($).
  • Tidak boleh diawali angka.
  • Tidak boleh mengandung spasi.
  • Tidak boleh menggunakan tanda hubung (-) sebagai bagian nama variabel.
  • Bersifat case-sensitive, sehingga nama dan Nama dianggap berbeda.

O. Aktivitas 11 – Debugging

Kesalahan pada kode awal: nama variabel tidak boleh memakai spasi atau diawali angka.

// Kode yang sudah diperbaiki
let namaSiswa = "Fajrin";
let umur = 16;
let kelasDua = "X PPLG 2";
console.log(namaSiswa);
console.log(umur);
console.log(kelasDua);
Kesalahan yang ditemukan:
  1. let nama siswa mengandung spasi.
  2. let 2kelas diawali angka.
  3. Pemanggilan console.log(nama siswa) tidak valid karena nama variabel mengandung spasi.

Q. Aktivitas 13 – Think Pair Share

Kesimpulan kelompok:
Programmer membutuhkan variabel untuk menyimpan data di dalam memori, memanggilnya kembali, dan mengolah atau memperbarui nilainya ketika program berjalan. Dengan variabel, program menjadi lebih terstruktur dan tidak perlu menuliskan data yang sama berulang kali.

S. Refleksi 3–2–1

3 hal yang dipelajari:
  1. Cara membuat variabel menggunakan let dan const.
  2. Aturan penamaan variabel yang benar.
  3. Cara menampilkan data menggunakan console.log().
2 hal yang masih perlu dilatih:
  1. Memahami berbagai jenis tipe data JavaScript.
  2. Membaca dan memperbaiki pesan kesalahan pada Console.
1 hal yang ingin dicoba:
  1. Membuat aplikasi sederhana seperti kalkulator menggunakan variabel.

T. Kesimpulan

  • Variabel adalah tempat untuk menyimpan data di dalam program.
  • let digunakan untuk variabel yang nilainya dapat diubah.
  • const digunakan untuk variabel yang tidak dapat di-assign ulang.
  • console.log() digunakan untuk menampilkan isi variabel ke Console.
